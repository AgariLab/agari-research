# 1,000 场数据的完整训练覆盖实验

状态：2026-10-28 已登记实验设计并完成旧模型对照评测；完整轮次候选训练与配对结果尚未产生。

## 问题与假设

`baseline-1000-v1` 使用 900 场训练数据，但固定 GRP 100 / CQL 200 次更新只消费了
3,200 / 12,800 个样本，涉及 80 / 23 个训练半庄。独立原生计数显示完整训练分区包含
36,228 个 GRP 样本和 525,721 个 CQL 样本。因此原运行不能代表完整遍历该数据集。

本实验检验：保持数据、架构和损失超参数不变，将 GRP 与 CQL 各训练一个完整轮次，
是否降低完整验证分区上的 GRP 交叉熵，以及是否改善导出 PPO 对固定弱对手池的结果。
两个判断分别记录；样本覆盖完整本身不证明棋力提高。

## 固定条件

- 数据：`datasets/manifests/selfplay-v1/split-v1.json`，摘要
  `39194c82b1f3bb8bff219425dc0ffa06ed2f0468e94f4fbd13f73d158048e4d3`。
- 划分：900 个训练半庄、50 个验证半庄、50 个冻结测试半庄；测试内容保持不读。
- 规则：RiichiEnv 0.4.10，Tenhou 四人赤牌半庄；不使用实验 fork wheel。
- 随机种子 2026、CPU 单线程、`local-small.json` 的模型架构及损失超参数。
- 新候选仅将 GRP / CQL 更新预算改为各 1 个完整 epoch；PPO 仍为 4 次更新。
- 基准 PPO 权重：`models/baseline-1000-v1/ppo.pt`，SHA-256
  `9a6894864cb0bbebaa0bca0b5fd373b2ce165deb5dc9e00a9e17524491017261`。
- 新旧模型均通过同一公共 Agent 接口重新评测，记录各自实际权重和运行源码。
  推理使用已提交的 research `723b81090944ecc430c2be331ba1cba364ab41b6` 源码快照，
  kit 保持 `9e3e866a046e40fecf94d03d315c9cc000d015b1`；训练代码开发不改变评测中的推理实现。

## 覆盖与恢复验收

独立计数证据在外置 `runs/baseline-coverage-audit-v1/native-sample-counts.json`：

| 分区 | 半庄 | 局 | GRP 样本 | CQL 样本 |
| --- | ---: | ---: | ---: | ---: |
| train | 900 | 9,057 | 36,228 | 525,721 |
| validation | 50 | 420 | 1,680 | 24,603 |

计数使用原生 `MjaiReplay` 的 Kyoku 和默认 `steps(player)` 接口，并核对冻结文件收据。
训练流必须与这些计数一致，不能丢弃最后不足 batch 的样本或跨轮次补齐。
batch size 为 32 / 64 时，预期分别为 1,133 / 8,215 次更新，末批为 4 / 25 个样本。
精确恢复需另以非整除 batch、跨 epoch 边界的有界运行检验全部检查点状态。
检查点写入间隔可调整，以减少外置盘写入；轮次结束、阶段结束和显式中断均须保存。

## 对照与报告

阶段结束验证全部 50 场，不以原先前 128 个验证样本的指标作为对照。
基准全量 GRP 交叉熵为 1.38431、准确率为 27.0238%；CQL loss 为 8.63535。
CQL 的回报目标由所训练的 GRP 产生，两个运行的 GRP 不同，因此 CQL loss 不可直接当作同目标下的优劣比较。

旧、新 PPO 使用相同的独立评测 seed 600000–600249，各四座轮换，共各 1,000 个半庄；
对手固定为 `efficiency`、`random`、`tsumogiri`。报告平均顺位、名次率、得失点、
候选决策延迟、非法动作与异常数；差值区间按配对种子组计算 bootstrap 95% 区间。
新模型减旧模型的平均顺位差为负表示改善，区间包含 0 时结果不确定。
所有结果均保留；不根据结果更换种子或删去不利对局。

这是小规模筛选，样本量和对手强度不足以通过计划中的正式晋级门槛。
后续 10,000 场自博弈数据属于独立数据集，本实验不混入其中的记录。
实际耗时、样本覆盖、模型哈希和全部评测结果在完成后补充，不预先宣称成功。

配对比较工具为 `scripts/compare_evaluations.py`。它要求两边全部完成，核对引擎二进制、
kit 源码、规则、Python、固定对手身份，以及候选自身的 factory、源码和非 artifact 推理参数；
允许候选模型权重不同，拒绝缺失／重复座位及分数与顺位不一致的结果。
运行目录和报告均为外置存储下的相对路径：

```sh
python3 ../agari-kit/scripts/with_storage.py uv run --frozen python scripts/compare_evaluations.py \
  --baseline runs/coverage-1000-baseline-eval-v1 \
  --candidate runs/coverage-1000-candidate-eval-v1 \
  --output runs/coverage-1000-comparison-v1/report.json
```

这条比较命令须等候选训练和两次评测完成后执行。
